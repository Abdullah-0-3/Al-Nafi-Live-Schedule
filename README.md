# **Al Nafi Live Class Schedule**

---

### **What Does This Project Do?**

- 🖥️ Retrieves live class information from [Al Nafi](https://alnafi.com/live-schdule).
- 🔍 Filters the data to find specific class schedules.
- 📧 Sends an email notification if there’s a class today.
- 🎉 Makes life easier by automating updates!

---

### **What Does This Project Include?**

- 🚀 **Python Selenium**: Automates web scraping.
- 🍲 **Beautiful Soup**: For parsing and filtering data.
- ✉️ **Email Script**: Sends out daily notifications.

---

### **How to Use This?**

1. **Clone the Repository**  
   ```powershell
   git clone <repository-url>
   ```

2. **Make a .env file**
    ```python
    EMAIL=your_email@email.com
    PASSWORD=email_passord
    SMTP_SERVER=smtp.gmail.com
    SMTP_PORT=587
    ```

3. **Install requriements for this project**
    ```powershell
    pip install -r requirements.txt
    ```

4. **Run the Python File**
    ```powershell
    python main.py
    ```
